# Sotto

[English](README.md) | Русский

Локальный голосовой диктант для Windows с портом на macOS. Нажимаете горячую
клавишу, говорите — и текст появляется в том окне, где вы печатали.

```text
горячая клавиша -> запись голоса -> локальное распознавание ->
необязательное LLM-форматирование -> вставка/копирование результата
```

По умолчанию распознавание полностью идёт на устройстве. Облачное
распознавание речи и LLM-форматирование текста существуют, но включаются
явно: пока вы сами не настроите провайдера, ничего не покидает компьютер.
См. [Приватность](docs/privacy.md).

## Установка

Скачайте последнюю сборку со страницы [Releases](../../releases/latest).

**Windows** — запустите установщик `Sotto_<версия>_x64-setup.exe`. Windows 11
уже содержит нужный приложению WebView2; на Windows 10 установщик предложит
его поставить. SmartScreen предупреждает о неизвестном издателе:
**Подробнее** → **Выполнить в любом случае**.

**macOS** — откройте DMG и перетащите Sotto в Applications. Gatekeeper
блокирует первый запуск; разрешите его в **System Settings** →
**Privacy & Security** → **Open Anyway**. Порт работоспособен, но
выверен меньше, чем Windows, — что проверяется на каждой платформе, описано
в [Platform support](docs/platforms.md).

Оба предупреждения честные: сборки не подписаны сертификатом издателя
(нет Authenticode, нет Apple Developer ID), поэтому система не может понять,
кто их выпустил. Проверить самим можно то, что файл — именно тот, который
произвёл релизный workflow: каждый релиз прикладывает `SHA256SUMS.txt`, а
артефакты обновления подписаны ключом minisign. См.
[Verifying a download](docs/verifying-downloads.md).

Приложение обновляется само: релизы подписаны этим ключом minisign и
проверяются перед установкой.

## Что умеет

- **Диктант по горячей клавише** в активное окно, с оверлеем состояния.
- **Локальные модели речи** — `whisper.cpp` везде, плюс бандлы `sherpa-onnx`
  на Windows и macOS (GigaAM, Parakeet, Canary, Moonshine, SenseVoice,
  Zipformer). Две из них отдают текст, пока вы ещё говорите.
  См. [Models](docs/models.md).
- **Расшифровка файлов** — приложите запись в панели «Обработать текст»,
  и текст вернётся туда же, не трогая активное окно и историю.
- **Необязательная LLM-обработка** — пунктуация, форматирование и свои
  промпты через провайдеров, совместимых с OpenAI.
- **Текстовые правила** — замены и словари применяются до того, как результат
  попадёт на место.
- **История и статистика**, хранятся локально в SQLite. Прошлую запись можно
  прогнать через любой сохранённый LLM-профиль: результат сначала показывают,
  и он заменяет сохранённый текст, только если вы его принимаете.

## Приватность

Речь расшифровывается на вашей машине. Записи никуда не выгружаются, пока вы
явно не включите облачного провайдера.

Обезличенная продуктовая телеметрия включена по умолчанию и отключается в
Settings → Advanced. Она не содержит ни аудио, ни расшифровок, ни диктуемого
вами текста. [Telemetry](docs/telemetry.md) документирует каждое событие и
свойство, которое отправляется; [Privacy](docs/privacy.md) описывает всю
сетевую картину целиком.

## Текущее состояние

- Версия: `0.0.4`
- Настольная оболочка: бэкенд **Tauri 2 + Rust**, фронтенд
  **React 19 / TypeScript / Vite**
- Речевой бэкенд: **`whisper-rs`** (whisper.cpp, GGML-модели) — полностью
  нативный, без Python
- Второй речевой бэкенд (Windows/macOS): **`sherpa-onnx`**, только CPU,
  каждый бандл зафиксирован на точный манифест артефактов и свой список
  языков
- Данные: SQLite (`rusqlite`, bundled) для истории и статистики
- Разделы: Settings, Models, Text, LLM processing, Integrations, History,
  Statistics
