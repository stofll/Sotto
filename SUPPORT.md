# Support

Start with the [documentation index](docs/README.md), especially
[platform support](docs/platforms.md), [models](docs/models.md), and
[troubleshooting](docs/troubleshooting.md). Search existing issues before
opening a new one.

For a reproducible bug, use the bug report template and include:

- app version and installation source;
- operating system, version, architecture, and relevant hardware;
- selected model and whether the operation was microphone or file based;
- exact steps, expected result, actual result, and sanitized logs.

Do not attach API keys, transcripts, clipboard contents, recordings, or private
provider responses. Security vulnerabilities belong in the private reporting
flow described by [`SECURITY.md`](SECURITY.md).

This project does not currently promise a support SLA. Maintainers and
contributors may be able to help with supported targets first; experimental or
CI-only platforms may require a local reproduction.
