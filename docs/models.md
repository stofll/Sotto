# Локальные модели

Локальное распознавание идёт двумя движками, и разница между ними видна
пользователю, поэтому каталог называет её вслух.

* **Whisper** через `whisper.cpp`: каталоговые GGML `.bin` и пользовательские
  `.bin` в каталоге моделей. Пользовательский файл должен быть совместим с
  `whisper.cpp`; приложение проверяет расширение и размер, но не умеет
  определить архитектуру произвольного GGML до загрузки. Многоязычные сборки
  (`tiny`, `base`, `small`, `medium`, `large-v3`, `turbo`) и английские
  (`*.en`) стоят в каталоге рядом; язык — свойство модели, а не часть её
  названия.
* **sherpa-onnx** на Windows: закрытый набор бандлов, каждый со своим
  семейством и своим списком языков. Произвольные ONNX-файлы намеренно не
  подхватываются: несовместимый граф может выбросить исключение внутри C++
  FFI и завершить процесс.

## Семейства sherpa

Движок выбирается по манифесту, а не по имени файла: `ModelEngine` знает,
какие роли артефактов обязательны для семейства, и по этому же знанию тесты
проверяют полноту манифеста.

| Семейство | Модель | Движок | Языки | Размер |
|---|---|---|---|---|
| GigaAM | GigaAM v3 | NeMo CTC | ru | 214 MB |
| Canary | Canary 180M Flash | Canary | en | 198 MB |
| Moonshine | Moonshine base | Moonshine | en | 274 MB |
| SenseVoice | SenseVoice small | SenseVoice | zh, en, ja, ko, yue | 229 MB |
| Zipformer | Zipformer | трансдьюсер | ru | 70 MB |
| Zipformer | Zipformer small | потоковый трансдьюсер | ru | 27 MB |
| Parakeet | Parakeet unified | потоковый трансдьюсер | en | 632 MB |
| Parakeet | Parakeet TDT v2 | трансдьюсер | en | 631 MB |
| Parakeet | Parakeet TDT v3 | трансдьюсер | многоязычный список | 639 MB |

Все они идут на CPU-провайдере ONNX Runtime. Переключатель CPU/GPU относится
только к Whisper, и интерфейс на sherpa-модели его не показывает.

Квантование каталог показывает там же, где вес: `int8` у sherpa-бандлов,
`q8_0` у части сборок Whisper. Оно объясняет, почему модель весит
меньше ожидаемого, и стоит рядом с весом, а не в названии.

### Языки закрыты списком

Модель, которую просят о чужом языке, не падает — она молча выдаёт мусор.
Поэтому у каждого бандла список языков записан в манифесте, и несовместимая
пара «модель + язык» отвергается до вызова FFI, с внятным сообщением.
`None` в этом поле означает многоязычную модель без ограничений.

### Потоковые модели

Только `SherpaStreamingTransducer` отдаёт текст по ходу речи; остальные
молчат до конца записи. Живой предпросмотр в оверлее выбирает модель именно
по этому признаку. «Потоковая» — свойство модели в карточке каталога, а не
часть её названия.

### Проверка артефактов

Перед вызовом sherpa все файлы бандла сверяются с закрытым реестром SHA-256;
URL зафиксированы на upstream-коммит. Неполная или изменённая папка не
считается установленной. Загрузчик собирает бандл в staging-каталоге и только
затем атомарно публикует подпапку — прерванная загрузка не оставляет
полуустановленную модель, а докачивается с того места, где остановилась.

## Каталог моделей

По умолчанию `%LOCALAPPDATA%/whisper-desktop/models` (Linux/macOS используют
системный cache directory). Путь можно переопределить переменной
`SPEECH_TO_TEXT_MODELS_DIR`.

Для Whisper допускается положить совместимый файл `*.bin` непосредственно в
этот каталог. Например, файл `ggml-large-v3-turbo-q5_0.bin` появится как
пользовательская модель. Файлы с идентификаторами встроенного каталога не
публикуются повторно, а удалить их через UI нельзя.

Каждый sherpa-бандл живёт в закрытой подпапке с именем из манифеста
(`gigaam-v3/`, `parakeet-tdt-v3/`, `zipformer-ru-streaming/` и так далее).

## Нативные библиотеки Sherpa

Крейт `sherpa-rs` 0.6.8 подтягивает проверенные бинарные библиотеки Sherpa-
ONNX/ONNX Runtime во время Cargo-сборки. Разработческая сборка и тесты
Windows работают с ними из Cargo target directory. Windows Tauri bundle автоматически
стейджит пять нужных DLL, кладёт их в ресурсы установщика и после
установки/обновления копирует рядом с исполняемым файлом, где их найдёт
Windows loader. На macOS/Linux семейства sherpa пока не публикуются и
Sherpa-зависимость не линкуется; эти release-таргеты остаются Whisper-only.
